# Agent readiness

Todd e Morgana ainda nao estao ativos. Este documento define o contrato antes da implementacao.

## O agente pode possuir
- identidade e background;
- preferencias de estilo;
- tendencia de argumentacao/opiniao;
- nivel de concisao;
- humor e forma de apresentar alternativas;
- configuracoes de voz futuras.

## O agente nao pode possuir separadamente
- banco de sessoes;
- memoria factual do usuario;
- factualidade propria;
- provider/modelo proprio por obrigacao;
- pipeline de tools duplicada;
- interpretador pragmatico independente.

## Regra central

O Campanario entende e lembra. O agente interpreta/expressa essa inteligencia com uma persona. Verdade, memoria e capacidades pertencem ao sistema.
