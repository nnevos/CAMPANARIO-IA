# Launcher, UI e build

Abra o Campanario pelo `CAMPANARIO.bat` desta pasta. A area Sistema da UI mostra modelo e build.

Neste safepoint deve aparecer:

`agent-personality-safepoint-v1.3.1`

Se aparecer outra build, provavelmente existe outra instalacao/servidor sendo aberto. Encerre a instancia antiga e inicie exclusivamente pelo launcher desta pasta.

O launcher nao deve reutilizar silenciosamente uma instancia antiga do Campanario na porta 8000.
