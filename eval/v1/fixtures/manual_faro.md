# Manual interno de Faro

O Projeto Faro opera apenas com relatórios locais e não consulta serviços externos por padrão.

O índice do Projeto Faro é atualizado manualmente às quartas-feiras.

O arquivo de referência do Projeto Faro se chama faro_referencia.md.

O responsável pelo protocolo interno do Projeto Faro é o setor de Arquivo.
