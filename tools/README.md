# Tools

- `windows/` — launchers individuais usados pelo menu raiz `CAMPANARIO.bat`.
- `maintenance/` — utilitarios de manutencao/backup para desenvolvimento.

Uso normal no Windows: prefira `CAMPANARIO.bat` na raiz. Os scripts individuais existem para automacao e diagnostico.

## Personalidade dos agentes

- `windows/TESTAR_PERSONALIDADES.bat`: quick comparison Todd/Morgana com o mesmo seed.
- `windows/TESTAR_PERSONALIDADES_MEGA.bat`: varios seeds/familias antes de congelar um baseline de persona.

Esses testes medem invariantes automaticamente e exigem revisao humana do transcript para qualidade fina de personalidade.
